Tasks:
python -m backend.main fooTask


Tests:
- Files must be in the format test_foo.py

- Run all tests from the terminal: 
python -m pytest

- Run a specific test class from the terminal: 
python -m pytest backend\tests_component\transactions\test_transaction_controller.py -v -s

- Run a specific test method from the terminal: 
python -m pytest backend\tests_component\transactions\test_transaction_controller.py::test_import_no_file -v -s
